# Stock Forecast Dashboard

Run locally with Python 3.11 or newer.

1. Install dependencies with `python -m pip install -r requirements.txt`.
2. Start the dashboard with `python -m streamlit run app.py`.

For Streamlit Community Cloud, put these files in a GitHub repository, select
that repository in Community Cloud, and set the app entry point to `app.py`.
The app checks for newer bars while the browser session is active.
